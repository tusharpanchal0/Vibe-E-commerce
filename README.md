# Vibe — E-Commerce Front-End

A responsive, front-end e-commerce demo built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Home page and dedicated shop page
- Product cards and category browsing
- Search and interactive shopping controls
- Wishlist and cart UI (demo)
- Light/dark theme toggle
- Responsive layout for desktop and mobile
- Product imagery loaded from Unsplash

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
3. Use the **Shop** link to open the full product listing.

No build tools or package installation are required.

## Note
This is a portfolio/demo project. Checkout does not process real payments, and product images require an internet connection.

## Tech stack
- HTML5
- CSS3
- JavaScript (ES6+)
